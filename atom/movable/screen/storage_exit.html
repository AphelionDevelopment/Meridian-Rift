storage_exit
/atom/movable/screen/storage_exit

The X button on the storage UI, sat next to the back arrow.

Closes the storage UI outright, no matter how deep into nested containers the viewer has browsed. The arrow beside it only steps back out one container.

Proc Details

proc
set_ui_style
(ui_style)

Themes this button to a UI style.

The storage interface stamps its style's icon file onto every element it owns, which would take this button's own icon with it, so this puts both the icon and the state back. A style we have no sprite for falls back to the default style rather than rendering blank.

Arguments:

  • ui_style - the icon file of the UI style being applied
