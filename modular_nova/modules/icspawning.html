Title: IC Spawning for admins

MODULE ID: ICSPAWNING

Description:

Adds a control click function to ghosts which allows an admin to spawn the player in via a supply pod or teleportation with effects. Extended to allow admins to save preferred spawn methods and outfits to custom slots.
