# Upstream drift review

Review referenced tgstation and Nova guidance after every tg batch merge, or monthly when no merge occurs. This is a maintainer review; automation reports drift and never rewrites policy.

Record:

```text
Reviewed on:
Reviewer:
Local HEAD:
Nova revision:
Guide paths and upstream references checked:
Changed authoritative rules:
Retained Meridian deltas and reasons:
Downstream patches or markers now removable:
Follow-up issues or PRs:
```

Compare [.github/guides](../../.github/guides), the [Nova handbook](../../modular_nova/readme.md), build workflows, and every external source named by [source authority](source-authority.md). Preserve pinned historical Nova guidance when its upstream is unavailable; document that limitation.
