Contains admin storage types

/datum/storage/adminA storage datum with infinite weight and many slots
/datum/storage/admin/bagUsed by bags like the trash bag/construction bag
/datum/storage/admin/bag/badminUsed by the subspace pocket
/datum/storage/admin/cytothecaStandalone for a dropped proc override
/datum/storage/admin/pockets2 slots, used by boots
/datum/armor/adminThis overrides the TG version to not have 100% damage 100% resistance. This is still worse than you'd expect.
/datum/armor/admin/badminThis one DOES have 100% damage resistance. It's not as good as you'd expect (allegedly).
/datum/armor/clothing_under/adminJumpsuits are unit tested for using a /datum/armor/clothing_under subtype, so the two above can't be used on the techsuits. Single inheritance means the values have to be repeated here rather than shared - keep them in step.
