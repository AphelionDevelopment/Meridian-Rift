Subspace RPED
/obj/item/storage/part_replacer/bluespace/admin

An admin-only bluespace RPED that manufactures stock parts on the fly.

Whenever it is used on a machine or an unbuilt frame it reads the required components off the target's circuit and tops itself up first, so nothing is ever short a part. Admins can also manufacture parts on demand, in bulk or by browsing subtypes, through the Alt-RMB menu.

on_interacting_with_atom
(/datum/source, /mob/living/user, /atom/target, /list/modifiers)

Tops the RPED up with whatever an unbuilt machine frame is still asking for.

Returns NONE unconditionally so the frame's own interaction still runs and installs the parts. Arguments:

  • source - the RPED itself
  • user - the mob holding the RPED
  • target - what is being clicked; only machine frames are handled
  • modifiers - click modifiers, unused

proc
pick_stock_part
(/mob/user, recurse, subtype)

Asks the user to pick a subtype to manufacture, one level of the type tree at a time.

Only the immediate children of the given root are listed, each labelled with how many subtypes it has of its own. Picking an entry that still has subtypes recurses into it rather than spawning, so an admin can walk down to the exact part they want; picking anything else fills the RPED with a batch of it. Arguments:

  • user - the mob operating the RPED
  • recurse - TRUE when this is a nested call, which makes the root itself selectable so it can be spawned directly
  • subtype - the root typepath to browse. Must pass valid_stock_part_types or nothing is listed

spawn_parts_for_components
(/mob/living/user, /list/required_components)

Fills the RPED with whatever a recipe asks for and it is not already holding.

req_components lists either item typepaths (materials, beakers) or /datum/stock_part subtypes, so every entry is handed off to whichever helper knows how to count and spawn that flavour of component. Arguments:

  • user - the mob operating the RPED, credited as the inserter for storage messages
  • required_components - assoc list of typepath to how many of it the recipe wants
